SStats.net API - Начало работы
22.06.2025 14:140 comments
SStats.net использует протокол REST API для взаимодействия. В ответе возвращается либо json, либо csv.

Основной адрес: https://api.sstats.net
Ссылка для передачи в ИИ: https://sstats.net/llms.txt Подробнее об интеграции с ИИ
Авторизация и лимиты
SStats.net API не требует авторизации. API доступно без регистрации и api ключа. Но у открытого досутпа существует ограничения на количество запросв. Это сделано для предотвращения ddos атак и возможности равномерного распредения квот между всеми пользователями.
Для обеспечения стабильного доступа с расширенными лимитами рекомендуется зарегистрироваться и получить бесплатный индивидуальный API ключ.

➔ Читайте инструкцию как получить API ключ и использовать его в запросах

Отправной точкой для работы с API может послужить получение всего списка лиг

1. Получение списка доступных лиг

Познакомьтесь с нашим Coverage. Данный запрос возвращает все имеющиеся лиги, страны, сезоны.
Используйте иденитфикаторы лиг и сезонов для извлечения матчей.

https://api.sstats.net/leagues

GET /Leagues
Пример ответа:

{
  "status": "ok",
  "data": [
    {
      "id": 39,
      "name": "Premier League",
      "country": {"code": "EN", "name": "England"},
      "seasons": [...]
    }
  ]
}
Далее можно перейти к получению списка матчей.

2. Загрузка матчей лиги за сезон

Этот запрос является основным, для получения списка матчей. Поддерживаются различные фильтры, по лигам, командам, дням и т.д
Для начала можно извлечь все матчи за сезон. Идентификаторы лиги и сезона мы узнали из предыдущего запроса.

https://api.sstats.net/Games/list?leagueid=39&year=2024

GET /Games/list?leagueid=39&year=2024
Параметры:

leagueid - ID лиги из предыдущего запроса
year - год сезона
limit - количество матчей (до 1000)
offset - смещение для пагинации
Примечание: Запрос не возвращает полную инфомрацию о матчах и является лишь кратким перечислением.
Подробную информацию необходимо запрашивать отдельным запросом для каждого матча

Подробную инструкцию по настройке фильтров читайте ➔ здесь

Дополнительные фильтры:

# Только завершенные матчи

# Матчи конкретной команды

3. Получение детальной информации о матче

А вот и главный запрос для получения подробных данных по матчу.
Запрос содержит самые актуальные на данный момент данные по матчу (кроме коэффициентов, они всегда доматчевые)

https://api.sstats.net/Games/971762

GET /Games/{id}
Возвращает:

Полную информацию о матче
Составы команд и статистику игроков
События матча (голы, карточки, замены)
Детальную статистику команд
Доматчевые коэффициенты
Если матч находится в лайве, то самые актуальные данные (статистика, события) будут в этом запросе. Кроме коэффициенов. Даже если матч идёт в лайве, коэффициенты будут доматчевые (самые последние, перед началом матча)
Т.к коэффициентов и букмекеров много, они вынесены в отдельный запрос.
Получение лайв коэффициентов, так же в отдельном запросе

4. Получение коэффициентов матча

https://api.sstats.net/Odds/1350725

# Доматчевые коэффициенты (доступны коэффициенты открытия и закрытия)

# Live-коэффициенты
GET /Odds/live/{gameId}

# Коэффициенты конкретного букмекера
GET /Odds/{gameId}?bookmakerId=4

# история движения коэффициентов в лайве
GET /oods/live-changes/{gameId}
5. Анализ с помощью Glicko 2

https://api.sstats.net/Games/glicko/1350725

GET /Games/glicko/{gameId}
Возвращает рейтинги команд и прогнозируемые вероятности побед на основе математической модели Glicko 2.

6. Анализ прибыльности стратегий

https://api.sstats.net/Games/profits?gameId=1350725&limit=25&thisLeague=true

GET /Games/profits?gameId={id}&limit=25
Показывает историческую прибыльность различных типов ставок для команд на основе их предыдущих матчей.

Список матчей​Copy link
Извлечение списка матчей. Данные о каждом матче возвращаются в сокращенном варианте (Id, время, статус, счет, названия команд их их ID, сезон, тур, коэффициенты).
Коэффициенты в сокращенном варианте: 1X2, Total. (на момент ближе к закрытию линии)

Для получения полной информации о конкретном матче используется /games/{id}

Одним запросом можно извлечь не более 1000 матчей. Чтобы извлечь остальные, нужно использовать несколько запросов, увеличивая &offset=N.

Например:
&offset=0&limit=10 - отобразит первые 10 матчей
&offset=10&limit=10 - отобразит следующие 10 матчей (пропуская первые 10)

Примеры:

Извлечение всех матчей по id лиги и году сезона
https://api.sstats.net/games/list?leagueid=183&year=2022

Извлечение всех матчей по id сезона 1DC9CB60-0958-11EE-B462-879841420925
https://api.sstats.net/games/list?seasonUid=1DC9CB60-0958-11EE-B462-879841420925

Извлечение всех матчей по id лиги и временному интервалу
https://api.sstats.net/games/list?leagueid=183&from=2022-10-30&to=2022-12-30

Предстоящие матчи команды
https://api.sstats.net/games/list?upcoming=true&team=529

Прошедшие матчи между командами когда они играли друг с другом (Head 2 Head)
https://api.sstats.net/games/list?ended=true&bothTeams=529,541

Данные матча​Copy link
Получить полные данные о конкретном матче.

Можно передать как числовой Id, использующийся в SStats.net так и строковый Id с Flashscore.com

Полные данные о матче, включая:

основная информация о матче (команды, счёт, статус, время)
статистика матча (удары, владение мячом, угловые и т.д.)
стартовые составы и тактические схемы команд
список игроков в составах с позициями
индивидуальная статистика игроков
события матча (голы, замены, карточки)
информация о стадионе, судье
доматчевые коэффициенты закрытия в сокращенном варианте. (Все коэффициенты здесь)
Частота обновления данных

Тип матча	Частота обновления
Лайв (идущие сейчас)	каждую минуту
Недавние (последние сутки)	каждые 15 минут
Доматчевые (до 30 дней назад)	раз в сутки

5	Начало второго тайма
6	Дополнительное время
7	Идёт серия пенальти
8	Матч завершён
9	Матч завершён после доп. времени
10	Матч завершён после серии пенальти

Список матчей​Copy link
Получение списка футбольных матчей с гибкими возможностями фильтрации и сортировки.

Основные возможности:

Поиск по конкретным матчам, лигам, сезонам и командам
Фильтрация по временным периодам (конкретная дата или диапазон)
Отбор матчей по статусу: завершенные, текущие (лайв) или предстоящие
Пагинация результатов (до 1000 матчей за запрос)
Сортировка по дате проведения матча
Примеры использования:

?Date=2025-06-21 - все матчи за конкретный день
?From=2025-06-01&To=2025-06-30 - матчи за период

?BothTeams=villa/ALztxK6e,chelsea/4fGZN2oK - матчи между двумя командами

Примеры работы с AI

Запрос к LLM:

Используя спецификацию OpenAPI из https://sstats.net/openapi/v1.json, сгенерируй на Python запрос 
для получения всех футбольных матчей, которые проходят сегодня.
LLM сгенерирует:

# Базовый URL API (можно заменить на свой, если отличается)
API_HOST = "https://api.sstats.net"
ENDPOINT = f"{API_HOST}/Games/list"

# Ваш API-ключ (если есть). 
# По умолчанию до 300 запросов в минуту без ключа, или 30/мин на IP.
API_KEY = os.getenv("SSTATS_API_KEY", None)

def fetch_todays_matches(timezone: int = 3):
    """
    Извлекает все матчи за сегодня, с учётом возможного 
    ограничения в 1000 матчей за один запрос.
    Возвращает список матчей (каждый — dict).
    """
    all_matches = []
    limit = 1000
    offset = 0

    # Параметры запроса: Today=True выбирает матчи за текущий день
    params = {
        "Today": True,
        "TimeZone": timezone,
        "limit": limit,
        "offset": offset,
    }
    if API_KEY:
        params["apikey"] = API_KEY

    while True:
        resp = requests.get(ENDPOINT, params=params)
        resp.raise_for_status()
        result = resp.json()

        # В спецификации ответ приходит в поле "data"
        matches = result.get("data", [])
        if not matches:
            break

        all_matches.extend(matches)
        offset += limit
        params["offset"] = offset

    return all_matches
Код сгенерирован моделью ChatGTP o4-mini-high (26.06.2025)

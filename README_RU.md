# Football Predictor — Стратегия Glicko2

Программа для прогнозирования футбольных матчей на основе динамики рейтингов Glicko2 с сайта sstats.net.

## Установка

```bash
pip install -r requirements.txt
```

## Использование

```bash
# Прогнозы на завтра (по умолчанию)
python predictor.py

# Прогнозы на сегодня
python predictor.py --today

# Прогнозы на конкретную дату
python predictor.py --date 2026-02-15

# Фильтр по лиге (например, 39 = Английская Премьер-Лига)
python predictor.py --league 39

# JSON-формат
python predictor.py --json

# Ограничить количество матчей для анализа
python predictor.py --max 20
```

## Стратегия

### 1. Оба графика вниз → ТМ 2.5 (Under 2.5 Goals)
Обе команды в плохой форме, рейтинги падают — ожидаем мало голов.

### 2. Оба графика вверх → Обе забьют (BTTS Yes)
Обе команды на подъёме — ожидаем активную атакующую игру.

### 3. Графики недавно пересеклись → Победа растущей команды
Если один график пошёл вверх, а другой вниз, и они недавно пересеклись — ставка на победу растущей команды.

### 4. Графики сходятся → Двойной шанс растущей команды
Если графики сближаются, растущая команда не проиграет (1X или X2).

### Дополнительные фильтры
- **RD (Rating Deviation)**: Отсеиваем команды с ненадёжным рейтингом (RD > 120)
- **xG**: Подтверждаем/опровергаем сигнал ожидаемыми голами
- **Минимальные коэффициенты**: Не берём заведомо невыгодные ставки
- **Историческая прибыльность**: Учитываем прошлую статистику типа ставки
- **R² тренда**: Оцениваем надёжность линейного тренда

## Конфигурация

Все параметры настраиваются в `config.py`:
- `API_KEY` — API-ключ sstats.net
- `TREND_MATCHES` — количество матчей для анализа тренда
- `MIN_CONFIDENCE` — минимальная уверенность для прогноза
- `MIN_ODDS` — минимальные коэффициенты по типам ставок
- Пороги трендов, конвергенции и т.д.

## Структура файлов

```
config.py           — Конфигурация и параметры
api_client.py       — HTTP-клиент для sstats.net API
glicko_analyzer.py  — Анализ трендов Glicko2 (ядро стратегии)
stats_validator.py  — Валидация сигналов дополнительной статистикой
predictor.py        — Главный скрипт (точка входа)
```
